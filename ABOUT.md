# About Basya Entertainment

Basya Entertainment is an independent collection of games, tools, software, stories, and interactive experiments.

The projects range from practical utilities and browser games to operating-system development, unusual web experiences, creative writing, and connected fictional worlds. Some are polished releases, while others are experiments that continue to evolve.

The collection is built around curiosity: trying an idea, giving it a distinct identity, and seeing how far it can go.

## Explore

Visit the [official Basya Entertainment website](https://www.basya.org/) to browse the complete collection and access current project pages, downloads, and releases.

This repository is a public introduction and official link hub. It does **not** contain the private source code for the Basya Entertainment website or its projects.
